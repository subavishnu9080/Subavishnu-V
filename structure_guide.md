# 📁 Workspace File Map & Guide

This guide explains the files in your portfolio project to help you navigate and edit them easily.

---

## 🟢 1. Files You Will Edit Most
These files contain the actual data, details, and resume text for your website.

* 📝 **[src/portfolioData.js](file:///d:/project/Portfolio/src/portfolioData.js)**
  * **What it is**: The main database of your website.
  * **When to edit**: If you want to change project descriptions, update your bio/location, add skills, or update dates.
* 📄 **[public/resume.html](file:///d:/project/Portfolio/public/resume.html)**
  * **What it is**: Your standalone printable resume.
  * **When to edit**: If you want to modify the printed format, text, or layout of your resume page.
* 🎨 **[src/index.css](file:///d:/project/Portfolio/src/index.css)**
  * **What it is**: Your global stylesheet containing custom scroll reveals, typewriter cursors, and custom color variables.
  * **When to edit**: If you want to change theme colors, fonts, or animation durations.

---

## 🔵 2. Under the Hood (React Source Code)
Located inside the `src/` folder. These files build the structure of your website.

* 💻 **[src/App.jsx](file:///d:/project/Portfolio/src/App.jsx)**: The central layout file that wires up all sections and implements the scroll reveal tracker.
* 🧱 **`src/components/`** (Folder): Modular sections of your homepage.
  * [Navbar.jsx](file:///d:/project/Portfolio/src/components/Navbar.jsx) — Header bar, mobile drawer, and light/dark theme switch.
  * [Hero.jsx](file:///d:/project/Portfolio/src/components/Hero.jsx) — Typewriter keyword banner and simulated coding IDE.
  * [About.jsx](file:///d:/project/Portfolio/src/components/About.jsx) — Facts and about text.
  * [Skills.jsx](file:///d:/project/Portfolio/src/components/Skills.jsx) — Interactive tech stack grid categorizing languages and testing tools.
  * [Projects.jsx](file:///d:/project/Portfolio/src/components/Projects.jsx) — Categorized project cards grid with mobile tap support.
  * [ProjectModal.jsx](file:///d:/project/Portfolio/src/components/ProjectModal.jsx) — Popup card displaying project problem, approach, and key features.
  * [Education.jsx](file:///d:/project/Portfolio/src/components/Education.jsx) — Timeline of academic achievements.
  * [Certifications.jsx](file:///d:/project/Portfolio/src/components/Certifications.jsx) — Grid showingIBM/Google qualifications.
  * [GitHubStats.jsx](file:///d:/project/Portfolio/src/components/GitHubStats.jsx) — Simulates live repository commits and language data.
  * [Contact.jsx](file:///d:/project/Portfolio/src/components/Contact.jsx) — Input form validating fields before send triggers.
  * [BrandIcons.jsx](file:///d:/project/Portfolio/src/components/BrandIcons.jsx) — Clean custom SVG components for GitHub & LinkedIn logos.

## 🟡 3. Configurations
System settings used by Vite, Tailwind CSS, and Node.js. You rarely need to edit these.

* ⚙️ **[vite.config.js](file:///d:/project/Portfolio/vite.config.js)**: Configures compiler outputs (e.g. enabling local relative paths).
* ⚙️ **[tailwind.config.js](file:///d:/project/Portfolio/tailwind.config.js)**: Holds layout extension tokens.
* ⚙️ **[postcss.config.js](file:///d:/project/Portfolio/postcss.config.js)**: Connects Tailwind CSS compilation plugins.
* ⚙️ **[package.json](file:///d:/project/Portfolio/package.json)**: Declares third-party libraries and command scripts (`dev`, `build`, `preview`).

---

## 🔴 4. Do Not Edit (Autogenerated Output)
* 📦 **`dist/`** (Folder)
  * **What it is**: The compiled production package. It contains minified HTML/CSS/JS ready to deploy to Vercel/Netlify.
  * **Note**: Do not edit files here directly (such as `dist/index.html` or `dist/assets/...`), because running `npm run build` will overwrite them.
* 📦 **`node_modules/`** (Folder): Internal packages required by React/Vite. Ignore this folder completely.
